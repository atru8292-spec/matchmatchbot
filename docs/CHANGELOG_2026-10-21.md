## 3. Время Мехико для напоминаний об ивенте и антибан-счётчика (`04103ec`)

- `scheduler.run_event_reminders(now=...)`: «сегодня/завтра» по `America/Mexico_City`.
  Раньше по UTC: в 18:00 17.11 по Мехико в UTC уже 18.11, «сегодня ивент» ушло бы на
  день раньше.
- Окно отправки напоминаний об ивенте 10:00–20:00 по Мехико (раньше — любой час тика,
  «завтра ивент» ушло бы около полуночи).
- `db._daily_counter_key`: суточный лимит холодных догонов по дате Мехико (раньше
  обнулялся в 18:00 по Мехико).
- `CDMX_TZ` в scheduler — `ZoneInfo("America/Mexico_City")` вместо фиксированного UTC−6.
- Тесты: 16–19 ноября, границы окна 09:59/10:00/19:59/20:00, 17.11 после 18:00 по Мехико.

## 4. Менеджер-бот: управление ботом (`ab63071`)

- Постоянная клавиатура «⏸ Остановить бота», «▶️ Включить бота», «📊 Статус» —
  приходит отдельным сообщением после /start и /help. Команды `/stop_bot`,
  `/start_bot`, `/status` делают то же.
- Только для `TG_MANAGER_ADMIN_IDS`; кнопки и команды от чужих id молча игнорируются.
- Остановить: сразу `bot_paused=1` (тот же `db.set_setting`, что и тумблер в CRM),
  ответ «Бот остановлен. Сейчас лидам отвечаешь только ты…», остальным админам —
  «Бот остановлен (кем: …)». Если уже на паузе — говорит об этом.
- Включить: только при `app_settings.tg_resume_enabled='1'` (ключ ставит владелица
  в день запуска, код его не создаёт), иначе «Включение бота из Телеграма пока закрыто.
  Напиши Арине.» Затем подтверждение «Да, включить» / «Отмена»; кнопка действует
  10 минут, флаг проверяется повторно в момент нажатия.
- Статус: `bot_paused`, `scheduler_enabled`, `event_active` и число лидов в ручном
  режиме (без заблокированных навсегда). Только чтение.
- `/stop <номер>` (блок лида) и `/start` не изменились.
