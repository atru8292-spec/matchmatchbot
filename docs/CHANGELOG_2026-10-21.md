## 3. Время Мехико для напоминаний об ивенте и антибан-счётчика (`04103ec`)

- `scheduler.run_event_reminders(now=...)`: «сегодня/завтра» по `America/Mexico_City`.
  Раньше по UTC: в 18:00 17.11 по Мехико в UTC уже 18.11, «сегодня ивент» ушло бы на
  день раньше.
- Окно отправки напоминаний об ивенте 10:00–20:00 по Мехико (раньше — любой час тика,
  «завтра ивент» ушло бы около полуночи).
- `db._daily_counter_key`: суточный лимит холодных догонов по дате Мехико (раньше
  обнулялся в 18:00 по Мехико).
- `CDMX_TZ` в scheduler — `ZoneInfo("America/Mexico_City")` вместо фиксированного UTC−6.
- Тесты: 16–19 ноября, границы окна 09:59/10:00/19:59/20:00, 17.11 после 18:00 по Мехико.

- Только для `TG_MANAGER_ADMIN_IDS`; кнопки и команды от чужих id молча игнорируются.
