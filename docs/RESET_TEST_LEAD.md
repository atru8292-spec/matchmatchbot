# Сброс тестового лида (начать диалог с ботом заново)

Работает только для номеров из списка тестовых (SILENT_BYPASS_PHONES и вкладка «Тест»
мини-CRM). На любой другой номер, включая реальных лидов, скрипт отказывает.

```bash
cd /Users/arina/Documents/matchmatch-bot
venv/bin/python -m scripts.reset_test_lead            # сухой прогон: что будет сброшено, ничего не пишет
venv/bin/python -m scripts.reset_test_lead --commit   # сброс
venv/bin/python -m scripts.reset_test_lead --phone wa_5215500008289 --commit   # другой тестовый номер
```

Что делает `--commit`:
1. бэкап строки лида, сообщений, смен стадий, фото и действий менеджера в `docs/backups/`
   и `~/matchmatch-backups/<дата>/` — до записи;
2. проверяет, что условие бьёт ровно по одному лиду;
3. удаляет только его сообщения;
4. сбрасывает анкету и память (имя, холост, возраст, профессия, интерес, фото, email,
   звонок), стадию до `new`, режим `auto`.

Журнал смен стадий, фото и действия менеджера остаются. Номер остаётся в списке тестовых.

Отличие от кнопки «Сбросить» во вкладке «Тест» мини-CRM: кнопка удаляет лида целиком вместе
со всей историей и без бэкапа; скрипт — только сообщения и анкету, с бэкапом.
