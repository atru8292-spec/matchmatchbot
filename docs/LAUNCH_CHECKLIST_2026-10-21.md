## 4. Запуск

Строго по порядку:

1. Открыть включение из Телеграма (ставит Арина):
   ```sql
   INSERT INTO app_settings (key, value, updated_at) VALUES ('tg_resume_enabled', '1', now())
   ON CONFLICT (key) DO UPDATE SET value = '1', updated_at = now();
   ```
2. Снять паузу: в менеджер-боте «▶️ Включить бота» → «Да, включить»
   (или тумблер паузы в CRM). Второму админу придёт «Бот включён (кем: …)».
3. Проверить «📊 Статус»: `bot_paused = 0`, `event_active = 1`, `scheduler_enabled = 0`.
4. Первые часы — смотреть ответы бота в CRM и журнал на сервере:
   `ssh root@2.26.71.254 'journalctl -u matchmatch-bot -f'`.
5. **Лидов, писавших на паузе, Аня открывает вручную**: бот их не подхватит после
   снятия паузы (сообщения помечены обработанными). Список приходит админам
   сводкой «⏸ Бот на паузе. С прошлой сводки написали …» раз в час.
6. **Через сутки**, если всё спокойно, включить авто-рассылки (догоны, напоминания
   об ивенте, напоминания о звонке): тумблер «Авто-рассылки» в CRM или
   ```sql
   UPDATE app_settings SET value = '1', updated_at = now() WHERE key = 'scheduler_enabled';
   ```
   Напоминания об ивенте уходят по времени Мехико с 10:00 до 20:00:
   «завтра ивент» — 17.11, «сегодня ивент» — 18.11, check-in оплатившим — 19.11.
