# MatchMatch WhatsApp Bot — проект

## Что это
AI-бот "Anna" отвечает на входящие WhatsApp-лиды агентства знакомств MatchMatch (CDMX).
Пишет от имени Anna (основательница), лид думает что общается с ней.
Мигрируем с n8n на Python-бэкенд.

## Стек
- Python 3.11+, FastAPI (вебхук-сервер)
- Supabase (Postgres) — база лидов, сообщений, сценариев
- OpenAI — генерация ответов (GPT-4.1) + транскрибация голосовых (Whisper)
- Wazzup24 — шлюз WhatsApp (приём/отправка)
- Telegram Bot — алерты об ошибках и эскалациях

## Архитектура (модули)
- `main.py` — FastAPI, эндпоинты вебхуков
- `normalize.py` — разбор входящего payload (текст/фото/голос/видео)
- `db.py` — все запросы к Supabase
- `ai.py` — вызов OpenAI + RAG по сценариям
- `sender.py` — разбивка ответа на сообщения, задержки, typing, отправка
- `escalation.py` — алерты в Telegram
- `debounce.py` — склейка серии быстрых сообщений от лида

## Жёсткие правила (соблюдать всегда)

НИКОГДА не говори "готово / работает / тесты прошли" без свежего запуска.
Перед любым заявлением о статусе:
1. ЗАПУСТИ команду (pytest / python -m ...) прямо сейчас, не кэш

Если не можешь проверить — не заявляй что работает.

### Код
- Никаких секретов в коде. Все ключи в .env (Wazzup, Supabase, OpenAI, Telegram)
- Каждая функция с обработкой ошибок — если падает, лог + алерт в Telegram
- Комментарии на русском, код на английском
- Простые решения предпочтительнее умных. Читаемость важнее краткости

### Бизнес-логика бота (не нарушать)
- Бот НЕ отвечает клиентам агентства (текущим и новым) — они идут к Anna лично.
  Есть whitelist номеров, для них бот молчит
- Бот НЕ даёт скидок и НЕ даёт телефоны девушек
- Услуга = servicio personalizado (15 mujeres/~6 meses, hasta 20, подбор вручную), инверсия
  **desde $10,000 USD**. Цену бот называет заинтересованному/на прямой вопрос; холодному —
  сначала ценность + квалификация, ведёт на звонок (после звонка — реальный подбор). VIP/тонкости
  — Anna на видеозвонке. Ивент — единая цена **6,000 MXN** (скидка за друга — 4,500/чел, ЕДИНСТВЕННОЕ
  исключение из "NO HAY DESCUENTOS"). Starter/подписки/$1,400 больше нет
- Если лид уходит после защиты цены сервиса — лестница: сервис → ивент (доступнее) → курсы
  (rusaencdmx.com/curso) — не отпускать молча, но и не давить всеми тремя разом
- Фильтры: возраст **28-76** (поднят с 65 владельцем, подтверждено), только soltero
  (separado/divorciado — считается soltero, НЕ блок), престижная профессия (AI решает по
  контексту), нужно фото — бот НЕ одобряет фото, где явно женщина (лид всегда мужчина)
- Блокирует и молчит: возраст вне 28-76, не холост, casual/escort, агрессия, неприемлемое фото
- Бот НИКОГДА не говорит слово "perfil" лиду (прямая правка владельца, 2026-08-12) — просить
  данные напрямую, без "para completar tu perfil"

### Антибан WhatsApp
- Задержки между сообщениями (2-8 сек по длине + рандом)
- Индикатор "печатает" перед каждым сообщением
- Рассылки по старой базе — порциями 20-30/день, не всё разом

## Как работать со мной (Claude Code)
1. Сначала план, потом код. Жди одобрения плана
2. После фичи — прогони субагента code-reviewer
3. Тесты обязательны для каждого модуля
4. При компакте контекста сохраняй: список изменённых файлов, команды тестов
5. **Перед тем как звать тестировать руками (Аню/Милу) — сначала сама прогони
   `scripts/smoke_test.py`** (реальные вызовы AI на паттернах багов, которые уже
   один раз ломались: повтор вопросов, ложные подтверждения, escort/aggression
   false-positives, лестница цена→ивент). Юнит-тесты (pytest) мокают AI почти
   везде — они не ловят регрессии в самом промпте, только в коде
6. У меня нет SSH на прод-сервер — деплой руками пользователя (см. ниже).
   После деплоя ПРОВЕРЬ, что реально накатилось (`git log -1` на сервере =
   `git log -1` локально) — не полагайся на то, что деплой был выполнен, если
   не подтверждено явно

## Команды проекта

# тесты (юнит, моки — не ловят регрессии в промпте)
